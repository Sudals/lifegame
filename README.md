# 졸업할 수 있을까? — 대학원 시뮬레이션

컨택 메일 한 통부터 졸업 심사까지, 실제 학회 데드라인 달력 위에서 연구력·스트레스·체력·운·돈을 관리하는 선택지 기반 라이프 시뮬레이션. (v0.3: 인공지능학과, 석사 루트)

- 기획안: [docs/01_기획안_대학원시뮬레이션.md](docs/01_기획안_대학원시뮬레이션.md)
- 개발환경: [docs/02_개발환경_대학원시뮬레이션.md](docs/02_개발환경_대학원시뮬레이션.md)

## 구조

```
apps/web          Vite + React 게임 본체 (Vercel 정적 배포)
  art/            도트 그래픽 생성기 (팔레트·캐릭터·배경·이펙트 → public/art/*.png)
  src/art/        무대(640x360)·캐릭터·타자기 대사·이펙트 런타임
api/              Vercel Functions — health / players / saves / runs(랭킹)
  _db/            Drizzle 스키마 + Neon 클라이언트
packages/engine   순수 TS 게임 로직 (시드 RNG, 주간 턴, 연구 파이프라인, 심사, 이벤트, 스코어, 밸런스 봇)
packages/content  연구실 8 · 주제 카드 53 · 학회 17 · 저널 9 · 아이디어 경로 9 · 이벤트 78 · 상점 35 · 활동 36 · 진로 7 (JSON + zod)
drizzle/          SQL 마이그레이션
scripts/          로컬 서버(serve.ts), 마이그레이션, DB 스모크 테스트
neon.ts           Neon 서비스 선언 (.neon 링크 파일은 neon init/link가 생성, git 제외)
```

## 시작하기

```bash
corepack enable   # 또는 npm i -g pnpm@9
pnpm install
neon env pull     # .env.local 에 DATABASE_URL, DATABASE_URL_UNPOOLED
pnpm db:migrate   # 테이블 생성 (처음 한 번)
pnpm dev          # http://localhost:5173
```

프로덕션 빌드 확인: `npm run build && npm start` → http://localhost:4173

## 주요 시스템 (v0.2)

- **주간 플래너**: 수면·연구·공부·휴식 + 고정 일정(생활·과제·잡무) 조정, 프리셋(성실/워라밸/밤샘), 남은 시간 자동 배분
- **동시 진행**: 연구력 70 이상이면 두 논문에 연구 시간을 나눠 투입 (전환 비용 10%)
- **돈**: 월급은 매달 1주차(인건비+과제수당+플래그 수입−생활비), 학기 시작 등록금(연구실 장학 비율), 채택 인센티브, 학위논문 심사비
- **이벤트 62종**: 상황 변수(`{venue}` 다가오는 학회, `{rival}`, `{season}`, `{paper}` …)와 대체 멘트, 비용이 드는 선택지(잔고 부족 시 선택 불가),
  확률 결과, 상태 플래그(조교·외주·연애·대출·헬스장·감기 …, `content/majors/ai/flags.json`), 후속 이벤트 예약(소개팅→데이트→연애, 인턴 지원→결과, 공저 약속→원고, 치과 미루기→악화)
- **주간 독백**: 이벤트 없는 주엔 마감·실험·잔고·계절·연애에 맞는 혼잣말

### v0.3 생활·돈·진로
- **활동 탭** (`activities.json`): 운동·여가·사람·데이트·성장·알바/대회 36종. 그 주 시간과 돈을 쓰고, 일부는 실력(연구력)·운에 따라 결과가 갈린다(경진대회·공모전·해커톤 상금, 소개팅). 쿨다운 있음
- **상점 탭** (`shop.json`): 음식(즉시)·영양제(4주 버프)·장비(영구 효율)·자기계발(영문 교정 → 논문 완성도)·선물(애정도)·취미 35종, 주간 구매 한도
- **연애**: 연인이 생기면 애정도(매주 감소) — 데이트·선물로 채우고, 30 이하면 서운함 이벤트, 0이면 이별
- **돈 구조**: 기본 인건비·월세 하향, 식비는 플래너에서 절약/보통/여유 선택(매주 지출), 과제 수주(연구재단·정부 R&D·기업 과제 제안서 → 선정 시 월 +30~45만)로 수입 증가
- **학자금 대출**: 100만 원 단위·한도 1,200만·연 1.7% (월급날 이자), 잔고가 마이너스면 안내. 상점·은행 탭에서 상환
- **졸업 정산**: 순자산(잔고−대출)이 `자산` 점수, 진로별 **안착도**(논문·연구력·네트워크·추천·평판·현장 경험·웰빙·재정·운·졸업 시기 가중) → 대성공~위기 5단계 1년 후 이야기 + 도움이 된/발목 잡은 요인 설명, `정착` 점수
- 수면 6시간 미만이면 상담 효과 절반 (밤샘의 위험은 돈이 아니라 수면에서)

## 테스트

```bash
pnpm test                                  # 콘텐츠 스키마 + 엔진 단위테스트 + 몬테카를로 밸런스(전략 3종 × 150회)
pnpm --filter @grad-sim/engine sim         # 밸런스 상세 리포트
pnpm db:smoke                              # Neon 왕복 테스트
pnpm test:e2e                              # npm start 후: 봇 1회차 → 클라우드 세이브/로드 → 랭킹 등록/조회 → 테스트 행 정리
pnpm exec tsx scripts/ui-walkthrough.ts <폴더>   # npm start 후: 설치된 Chrome으로 실제 UI 플레이 + 스크린샷
```
