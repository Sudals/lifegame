# 대학원 시뮬레이션 (가제: 「졸업할 수 있을까?」) — 게임 기획안 v0.1

> 작성일: 2026-11-04 · 대상 버전: MVP (인공지능학과 단일 전공)

---

## 1. 개요

| 항목 | 내용 |
|---|---|
| 장르 | 선택지 기반 라이프 시뮬레이션 (비주얼노벨 + 육성) |
| 플랫폼 | 웹(Vercel 배포) → 추후 Windows exe (Electron) |
| 그래픽 | 2D 대화형 화면, 고해상도 도트(HD Pixel Art) |
| 플레이 타임 | 1회차 약 1.5~3시간 (석사 2년 / 석박통합 5~6년 선택) |
| 핵심 재미 | "연구실 고르기 → 버티기 → 논문 내기 → 졸업 후 진로"의 인생게임식 분기와 리플레이 |
| MVP 범위 | 전공: 인공지능학과 1개 / 실제 학회·저널 일정 반영 / 엔딩·스코어 |

### 1.1 한 줄 컨셉
대학원 컨택 메일 한 통부터 졸업 심사까지, **현실적인 학회 데드라인 달력** 위에서 연구력·스트레스·체력·운·돈을 관리하며 최고의 커리어 엔딩을 노리는 게임.

### 1.2 디자인 원칙
1. **현실 고증 + 과장된 유머**: 실제 학회 시즌, 리뷰어 2번, 리젝, 카메라레디의 리듬을 그대로. 단, 톤은 밝고 블랙코미디.
2. **모든 선택은 트레이드오프**: 과제 = 돈↑ 연구시간↓, 밤샘 = 진척↑ 체력↓.
3. **리플레이성**: 연구실·주제·운 이벤트 조합으로 매 회차 다른 이야기.
4. **데이터 드리븐**: 연구실/주제/학회/이벤트는 전부 JSON 콘텐츠로 분리 → 전공 확장 시 데이터만 추가.

## 2. 게임 흐름 (전체 루프)

```
[캐릭터 생성] → [연구실 탐색·컨택] → [면접/입시] → [입학]
   → [학기 루프: 주 단위 턴 × N] ──┬─ 수업/공부/연구/과제/휴식
                                   ├─ 아이디어 → 주제 선정 → 실험 → 작성 → 투고 → 리뷰 → 결과
                                   └─ 랜덤 이벤트 / 교수 미팅 / 학회 참석
   → [졸업 요건 충족] → [학위 심사] → [진로 선택] → [엔딩 & 최종 스코어]
```

### 2.1 단계별 상세

| 단계 | 기간(게임 내) | 주요 내용 |
|---|---|---|
| 캐릭터 생성 | - | 이름, 학부 배경(CS/수학/전자/비전공), 학부 성적, 초기 스탯 포인트 분배, 특성 1~2개 |
| 연구실 탐색 | 입학 전 3~6개월 (예: 9월~12월) | 연구실 리스트 열람, 정보 수집(선배 소문/홈페이지/논문 목록), 컨택 메일 작성(선택지) |
| 면접 | 1~2주 | 교수 질문 선택지, 결과에 따라 합격/대기/불합격 |
| 석사 | 4학기 (2년) | 수업 이수, 졸업 논문 1편 + (선택) 학회 논문 |
| 박사/석박통합 | 4~6년 | 퀄 시험, 프로포절, 다수 논문, 디펜스 |
| 졸업·진로 | - | 실적 기반 진로 오퍼 → 플레이어 선택 → 엔딩 |

> 입학 시점은 3월(전기) / 9월(후기) 중 선택. 학회 달력과 맞물리며 난이도가 달라짐.

## 3. 시간 시스템

### 3.1 턴 구조
- **기본 턴 = 1주.** 게임 내 날짜는 실제 달력(연-월-주)을 사용.
- 매 턴, 플레이어는 **주간 시간표(총 168시간)** 를 배분.
  - 수면 (원하는 시간 직접 설정: 4~10시간/일)
  - 연구 (아이디어/실험/작성 중 현재 단계에 투입)
  - 공부 (논문 읽기, 강의, 온라인 코스)
  - 과제(프로젝트) 업무 — 연구실 과제량에 따라 **강제 할당 시간** 존재
  - 수업 (학기 중 고정)
  - 잡무 (연구실 평판의 '잡무' 수치에 비례해 강제 발생)
  - 휴식/취미/알바
- 데드라인 직전에는 **일 단위 턴(크런치 모드)** 으로 전환 → 긴장감 연출.

## 4. 플레이어 파라미터

### 4.1 핵심 5대 스탯

| 스탯 | 범위 | 증가 요인 | 감소 요인 | 영향 |
|---|---|---|---|---|
| **연구력** (Research) | 0~100+ (세부: 이론/구현/작성/발표) | 공부, 논문 읽기, 학회 참여(기간 한정), 교수/랩 미팅, 과제 성과, 실험 성공 | 장기간 연구 미투입 시 미세 감소 | 아이디어 품질, 실험 성공률, 논문 완성도 |
| **스트레스** (Stress) | 0~100 | 데드라인, 리젝, 교수 압박, 잡무, 돈 부족 | 휴식, 취미, 채택, 여행, 상담/정신과 | 70↑ 효율 저하, 90↑ "번아웃" 상태 |
| **체력** (Stamina) | 0~100 | 수면, 운동, 식사 | 수면 부족, 밤샘, 과제 과다 | 낮으면 시간당 효율↓, 0이면 강제 입원/휴식 이벤트 |
| **운** (Luck) | 숨김 0~100 (힌트만 표시) | 특성, 특정 이벤트(점집, 행운 아이템) | 거의 고정 | 리뷰어 배정, 랜덤 이벤트, 실험 우연 발견 |
| **돈** (Money) | 원(₩) | 연구실 급여(인건비), 과제 수당, 장학금, 알바, 인턴 | 월세·식비(월 고정비), 학회 참가비, 저널 APC, 진료비, 장비 | 0 미만 → 대출/알바 강제/중도 포기 위험 |

### 4.2 보조 수치 (숨김 or 서브 UI)
- **교수 신뢰도**: 미팅 성과·마감 준수로 상승 → 저자 순서, 추천서 품질, 졸업 승인 속도.
- **연구실 관계도**: 선배/동기와의 관계 → 공동저자 기회, 도움 이벤트.
- **네트워크**: 학회·인턴에서 획득 → 진로 오퍼 개수/질.
- **멘탈 상태 플래그**: 정상 / 피로 / 번아웃 / 치료 중.

### 4.3 스트레스·멘탈 시스템
- 스트레스 **80 이상이 4주 지속** → "정신과 상담 필요" 알림.
- 정신과/상담 선택 시: 돈 소모 + 주 2~4시간 소모, 스트레스 감소율↑, 회복 버프.
- 방치 시: 번아웃(모든 효율 -40%), 휴학 이벤트, 최악은 중도 포기 엔딩.
- 톤 가이드: 정신건강 치료를 **긍정적이고 정상적인 회복 수단**으로 묘사. 조롱·희화화 금지. 게임 내 "도움 받기"는 항상 좋은 선택으로 설계.

### 4.4 체력·수면 시스템
- 수면 시간 슬라이더(일 단위 평균). 6시간 미만 누적 시 '수면 부채' 적립.
- 수면 부채 → 체력 회복량 감소, 실험 실수 확률↑, 미팅 실수 이벤트.
- 카페인 아이템: 단기 효율↑, 다음 주 체력↓.

## 5. 연구실(Lab) 시스템

### 5.1 연구실 속성

| 속성 | 설명 | 게임 효과 |
|---|---|---|
| 급여(인건비) | 월 지급액 | 돈 수입 |
| 연구실적 | 교수/랩의 최근 논문 레벨 | 아이디에이션·주제선정·논문작성 시 **완성도 보너스 확률** |
| 평판 - 인간성 | 교수 성격(1~5) | 미팅 압박 이벤트 빈도, 스트레스 증가량 |
| 평판 - 잡무 | 행정·장비관리·행사 빈도(1~5) | 주당 강제 잡무 시간 |
| 과제량 | 정부·기업 과제 수 | 급여↑ / 체력·연구시간↓, 과제 성과로 연구력 소폭↑ |
| 연구 분야 | 주력 토픽 | 해당 토픽 선택 시 보너스, 다른 토픽 시 페널티 |
| GPU 자원 | 컴퓨팅 등급 | 대규모 실험 주제 가능 여부, 실험 속도 |
| 졸업 기간 | 평균 졸업 소요 | 숨김 값, 선배 소문으로 힌트 |
| 지도 스타일 | 방임형/마이크로매니징/협업형 | 자율성 vs 가이드 |
| 산학/네트워크 | 기업 연계 | 인턴·취업 오퍼 보너스 |

### 5.2 MVP 연구실 예시 (가상, 인공지능학과)

| 연구실 | 급여 | 실적 | 인간성 | 잡무 | 과제 | GPU | 특징 |
|---|---|---|---|---|---|---|---|
| 거대언어모델 연구실 (김교수) | 중상 | ★★★★★ | ★★ | ★★★ | 많음 | A | 탑티어 다수, 압박 심함 |
| 비전·생성모델 연구실 (박교수) | 중 | ★★★★ | ★★★★ | ★★ | 보통 | B | 균형형, 추천 랩 |
| 강화학습·로보틱스 연구실 (이교수) | 상 | ★★★ | ★★★ | ★★★★ | 매우 많음 | B | 돈은 많지만 과제 지옥 |
| 효율적 AI·경량화 연구실 (최교수) | 중하 | ★★★ | ★★★★★ | ★ | 적음 | C | 천사 교수, 자원 부족 |
| 신임 교수 연구실 (정교수) | 하 | ★★ (잠재력 ★★★★★) | ★★★★ | ★★ | 적음 | B | 랜덤성 큼, 교수와 같이 성장 |
| 산학 협력 AI 연구실 (한교수) | 상 | ★★ | ★★★ | ★★★ | 기업 과제 | A | 취업 연계 최고, 논문은 약함 |
| 이론 ML 연구실 (윤교수) | 중하 | ★★★★ | ★★★ | ★ | 거의 없음 | D | JMLR/COLT 보너스, 수학 요구 |

### 5.3 컨택 & 입시
- **정보 수집 행동**: 홈페이지 읽기(무료), 논문 읽기(시간), 선배 연락(운/관계), 커뮤니티 소문(정확도 랜덤).
- **컨택 메일 작성**: 템플릿 조각 선택지(관심 주제/자기 어필/질문) → 답장 확률 계산.
- **면접**: 3~5문항 선택지. 연구력·준비도·운 판정.
- 결과: 합격 / 조건부 합격(인턴 후) / 불합격 → 다른 연구실 재컨택, 너무 늦으면 '재수' 루트.

## 6. 연구(논문) 파이프라인 — 핵심 시스템

```
① 아이디어 탐색 → ② 주제 선정 → ③ 관련연구 조사 → ④ 실험 설계 → ⑤ 실험 실행(반복)
→ ⑥ 논문 작성 → ⑦ 교수 리뷰 → ⑧ 투고처 선택 → ⑨ 심사 → ⑩ 리버탈/리비전 → ⑪ 결과
```

### 6.1 ① 아이디어 탐색 (선택지가 매우 다양해야 하는 구간)
아이디어 획득 경로(각각 다른 아이디어 풀과 확률):

| 경로 | 비용 | 특징 |
|---|---|---|
| 최신 arXiv 정독 | 시간 많음 | 트렌디, 경쟁 높음 |
| 고전 논문 재해석 | 시간 보통 | 참신성↑ 확률, 트렌드 낮음 |
| 교수 미팅에서 하사받기 | 교수 신뢰도 | 실적 보너스 적용, 자율성↓ |
| 선배 연구 확장 | 관계도 | 빠른 시작, 기여도 공유(공저) |
| 과제에서 파생 | 과제 시간 | 데이터·자원 확보, 산업 응용 |
| 학회 포스터 세션에서 영감 | 학회 참여 시 한정 | 고품질 아이디어 확률↑ |
| 샤워 중 번뜩임 | 휴식·운 | 랜덤, 가끔 대박 |
| 다른 분야 융합 (예: 철도·의료·법률 × AI) | 공부 시간 | 니치, 경쟁 낮음, 탑티어 확률 낮음 |
| 커뮤니티/트위터 토론 | 시간 소량 | 품질 랜덤, 선점 리스크 |

### 6.2 ② 주제 선정 — 주제 카드 시스템
각 아이디어는 **주제 카드**로 표현. 카드 속성:

| 속성 | 설명 |
|---|---|
| 분야 | LLM, 멀티모달, 생성모델(Diffusion), 강화학습, 컴퓨터비전, 그래프, 음성, 추천, AI 안전/정렬, 효율화(양자화·프루닝·조기종료), 연합학습, 설명가능 AI, 시계열, 로보틱스, AI for Science, 이론 등 |
| 유형 | 새로운 방법론 / 분석·벤치마크 / 데이터셋 / 응용 / 이론 / 서베이 |
| 참신성 | 1~5 |
| 난이도 | 1~5 (요구 연구력) |
| 컴퓨팅 요구 | GPU 등급 요구 (연구실 자원과 비교) |
| 트렌드 지수 | 게임 내 시간에 따라 변동 (예: 특정 분야 붐 → 하락) |
| 경쟁도 | 높으면 **선점(scooped) 이벤트** 확률↑ |
| 예상 소요 기간 | 주 단위 |
| 적합 투고처 | 학회/저널별 가중치 |

**주제 선정 선택지 예시**
- "이 주제, 일단 작게 시작해서 워크숍부터 낼까?" / "크게 키워서 NeurIPS 노릴까?"
- "남들이 다 하는 LLM으로 갈까, 비어있는 시계열로 갈까?"
- "교수님 주제를 받을까, 내 아이디어를 밀어붙일까?" (교수 신뢰도 vs 자율성 보너스)
- 주제 결합: 카드 2장 합성 → 신규 카드 (예: "효율화 × 멀티모달")

### 6.3 ③~⑤ 실험
- 매주 연구 시간 투입 → **진척도(%)** 상승. 진척 속도 = f(연구력, 체력, GPU, 난이도).
- 실험 결과 판정(주기적): 성공 / 애매 / 실패 / 의외의 발견(운).
- 실패 시 선택지: 방향 수정(피벗) / 하이퍼파라미터 지옥(시간 소모) / 포기 후 카드 폐기 / 네거티브 결과로 워크숍.
- 이벤트: 서버 다운, GPU 쟁탈전, 데이터 유출 실수, 버그 발견(채택 후 발견하면 대형 이벤트).

### 6.4 ⑥ 논문 작성 & 완성도
**논문 완성도(Paper Quality)** = 기본값(주제 참신성 × 실험 결과) + 작성 스킬 + 투입 시간 + **연구실 실적 보너스(확률적 +α)** + 교수 리뷰 반영도 − 급하게 쓴 페널티.
- 데드라인 크런치: 마지막 1주 일 단위 턴, 밤샘 선택 시 완성도↑ 체력↓↓.
- 교수 첨삭 루프: 교수 인간성에 따라 "빨간펜 폭격" 이벤트.

### 6.5 ⑧~⑪ 투고 & 심사
- 투고처 선택 화면: 마감 달력 + 예상 채택률 힌트(연구력 높을수록 정확).
- 심사 판정: `채택확률 = sigmoid(완성도 − 학회 컷 + 적합도 + 운 보정 + 리뷰어 랜덤)`
- 리뷰어 3~4명 점수 생성 (Reviewer 2는 항상 까다로움 연출).
- 리버탈 선택지: 정중한 반박 / 추가 실험 약속 / 일부 인정 → 점수 변동.
- 결과: Accept(Oral/Spotlight/Poster) / Reject → 리뷰 반영 후 다음 학회 재투고(완성도 소폭↑) / Withdraw.
- 동시 투고(중복 투고) 금지 규칙 → 위반 시 데스크 리젝·평판 하락 이벤트(교육적 요소).

## 8. 졸업 & 진로 & 스코어

### 8.1 졸업 요건 (연구실·학위별 상이, 데이터로 정의)
- 석사: 학점 이수 + 학위논문 + (랩 규정) 국내 학회 1편 이상
- 박사: 퀄 통과 + 프로포절 + 1저자 SCI/탑티어 N편 + 디펜스

### 8.2 진로 오퍼 (실적·네트워크·교수 신뢰도로 결정)
| 진로 | 주요 요구 조건 |
|---|---|
| 교수 임용 | 박사, 탑티어 다수, 추천서, 포닥 경력 |
| 해외 포닥 | 박사, 탑티어 + 네트워크 |
| 빅테크 리서치 사이언티스트 | 탑티어 1저자, 인턴 경력 |
| 빅테크/대기업 ML 엔지니어 | 구현 스탯, 과제/인턴 경험 |
| AI 스타트업 / 창업 | 산업 응용 실적, 운, 리스크 성향 |
| 국책 연구소 연구원 | 저널 실적, 과제 경험 |
| 박사 진학 | 석사 졸업 시 선택지 |
| 업계 이탈(전혀 다른 길) | 히든 엔딩 |
| 중도 포기 | 배드 엔딩(재도전 유도) |

### 8.3 최종 스코어 공식(초안)
```
최종점수 = Σ(논문 점수 × 저자 순서 가중치)
         + 진로 점수
         + 인용수 보너스(게임 내 시뮬레이션)
         + 졸업 소요 기간 보너스/페널티
         + 웰빙 보너스(평균 스트레스 낮을수록, 평균 수면)
         + 잔여 돈 보정
```
- 논문 점수 예: A+ 학회 Oral 120 / A+ Poster 100 / A 70 / B 40 / 워크숍 20 / 국내 10 / TPAMI 130 / IEEE Access 25
- 저자 가중치: 1저자 1.0 / 공동1저자 0.8 / 2저자 0.4 / 3저자 이하 0.2
- 등급: S / A / B / C / D + 칭호 ("리뷰어 2의 천적", "과제의 노예", "정시 퇴근 박사" 등)
- **웰빙 보너스**를 반드시 포함 → "건강하게 졸업하는 것"도 고득점 경로.

## 12. 밸런싱 가이드라인 (초기값)
- 석사 평범 플레이 기대 실적: 국내 1~2 + B~A급 1편 확률 50%.
- A+ 1저자 채택 확률(평균 플레이): 석사 기간 중 20~30%.
- 월 생활비 기준 예시: 고정비 90~120만원, 연구실 급여 80~250만원.
- 스트레스 자연 증가: 주당 +2~5 (데드라인 주간 +10~20).
- 체력 회복: 수면 7시간 기준 주당 +15, 5시간 이하 −10.
- 모든 수치는 `data/balance.json`에서 관리 → 플레이테스트 후 조정.
